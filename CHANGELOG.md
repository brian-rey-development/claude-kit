# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org).

## [0.1.0] - 2026-10-16

### Added

- `kit setup`, a guided setup that previews themes in the terminal and in a live iTerm2 window before it changes anything.
- `kit apply`, `kit preview`, `kit doctor` and `kit uninstall`, which records every change and restores the previous state exactly.
- `kit new-theme`, which makes a theme from an image with a palette that meets WCAG AA contrast.
- A status line built from widgets, with a layout engine that fits any terminal width, and `kit widgets` and `kit layout` to arrange it.
- The welcome card mod, which shows the theme's art above the prompt in the largest size that fits.
- A patched Monaco built on each Mac, whose icon character draws the theme's mascot.
- The Moonlit theme, with original CC0 art.
